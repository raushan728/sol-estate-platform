# Sol-Estate Platform
A decentralized Real World Asset (RWA) platform built on Solana.

[Website] | [Frontend Docs] | [Smart Contract Docs]

</div>

[Website]: https://sol-estate-platform.vercel.app/
[Frontend Docs]: app/README.md
[Smart Contract Docs]: programs/sol-estate-platform/README.md

This repository contains the source code for Sol-Estate, a fractionalized real estate investment platform built on the [Solana] blockchain. It includes an [Anchor]-based on-chain program for asset management and a [Next.js] client for the user marketplace and admin portal. 

[Solana]: https://solana.com/
[Anchor]: https://www.anchor-lang.com/
[Next.js]: https://nextjs.org/

## Project Structure

The project is divided into two main components. Please refer to their specific documentation for setup and usage instructions:

- **[Frontend Client (Next.js)](app/README.md):** The web-based marketplace and admin dashboard located in the `app/` directory.
- **[Smart Contract (Anchor/Rust)](programs/sol-estate-platform/README.md):** The on-chain asset logic and state management located in the `programs/sol-estate-platform/` directory.

## Quick Start

To build and test the entire project from the root directory:

```bash
yarn install
anchor build
anchor test
```
